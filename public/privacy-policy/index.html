Politique de confidentialité

Comment vos données sont collectées, utilisées et protégées.

Dernière mise à jour : 31 juillet 2026 Application mobile

1. Qui sommes-nous ?

DelyGes est une application mobile de gestion de livraisons et de comptabilité destinée aux livreurs.

Éditeur / marque : DelyGest

Co-éditeur / développeur : Ouedraogo Abdoul Wahab

Responsable / représentant : Soumahoro Yacouba

Localisation : Abidjan, Côte d'Ivoire

Contact : delygest@gmail.com

2. Données collectées

DelyGes ne collecte que les données strictement nécessaires au fonctionnement du service.

Données du compte

  • Nom complet
  • Adresse email
  • Numéro de téléphone
  • Mot de passe (géré de manière sécurisée par Firebase Authentication)
  • Identifiant unique du compte (UID Firebase)
  • Identifiant utilisateur local
  • SIRET (facultatif)
  • Type de véhicule (facultatif)
  • Statut TVA (facultatif)
  • Objectifs financiers (quotidien, mensuel)
  • Préférences de notifications

Données de livraison

  • Nom du destinataire
  • Téléphone du destinataire
  • Adresse de livraison
  • Valeur du colis
  • Frais de livraison
  • Type de paiement
  • Montant encaissé
  • Montant à reverser
  • Profit
  • Statut de la livraison
  • Notes éventuelles

Données des commerçants

  • Nom
  • Téléphone
  • Adresse

3. Finalités du traitement

  • Création et gestion de votre compte utilisateur.
  • Fonctionnement de l'application (gestion des livraisons, commerçants, statistiques).
  • Sauvegarde cloud et synchronisation de vos données entre vos appareils.
  • Envoi de notifications locales (rappels d'activité).
  • Amélioration du service et assistance utilisateur.

DelyGes est un outil de gestion destiné aux livreurs. Il n'est pas une plateforme de mise en relation entre livreurs et clients.

4. Où vos données sont-elles stockées ?

Composant Rôle Localisation
Firebase Authentication Compte utilisateur, email et mot de passe Cloud (Google, datacenter eur3)
Firebase Firestore Profil, livraisons, commerçants (synchronisation cloud) Cloud (Google, datacenter eur3)
SQLite Base de données locale de l'application (cache hors-ligne) Sur votre appareil
SecureStore Identifiant de session locale Sur votre appareil (stockage sécurisé)
AsyncStorage Persistance de session du SDK Firebase Authentication Sur votre appareil

L'application stocke une copie locale de vos données (SQLite) pour fonctionner hors-ligne et les synchronise avec Firestore lorsque vous êtes connecté.

5. Notifications

DelyGes utilise uniquement des notifications locales générées sur votre appareil (rappels de livraisons en attente, objectifs atteints, rappels d'inactivité). L'application n'utilise pas de notifications push distantes et n'envoie pas votre appareil vers un serveur de notification.

6. Données que nous ne collectons pas

  • Position géographique / localisation (aucune permission de localisation)
  • Photos, images ou caméra
  • Contacts de l'appareil
  • Données d'analyse de navigation (aucun service d'analytics intégré)
  • Identifiants publicitaires

7. Durée de conservation

Vos données sont conservées tant que votre compte est actif. Lorsque vous supprimez votre compte, vos données sont supprimées immédiatement et définitivement, en particulier :

  • le compte Firebase Authentication ;
  • le profil utilisateur, les livraisons et les commerçants dans Firestore ;
  • les données locales (SQLite) et la session sécurisée de l'appareil.

Aucune donnée personnelle n'est conservée après la suppression de votre compte, sauf si une obligation légale (comptable, fiscale ou judiciaire) l'exige : seules les données strictement nécessaires seraient alors conservées pendant la durée prévue par la loi.

8. Sécurité

  • Les échanges avec les services Firebase sont chiffrés (HTTPS/TLS).
  • Votre mot de passe est géré et sécurisé par Firebase Authentication.
  • Les règles de sécurité Firestore restreignent l'accès à vos seules données.
  • La session locale est stockée dans le stockage sécurisé de votre appareil.

9. Suppression du compte

Vous pouvez supprimer votre compte à tout moment depuis l'application : Paramètres → « Supprimer le compte ». Vous devrez confirmer votre identité en saisissant votre mot de passe. La suppression est immédiate et irréversible.

Vous pouvez également demander la suppression par email : delygest@gmail.com.

Consultez notre page dédiée : Supprimer mon compte DelyGes.

10. Vos droits

Vous disposez des droits suivants sur vos données personnelles, dans les limites prévues par la réglementation applicable :

  • Accès : savoir quelles données sont traitées.
  • Rectification : corriger vos informations.
  • Effacement : supprimer votre compte et vos données.
  • Portabilité : récupérer vos données.
  • Opposition et limitation du traitement.

Pour exercer ces droits, contactez-nous : delygest@gmail.com. Nous répondons dans un délai raisonnable, en règle générale sous 30 jours.
