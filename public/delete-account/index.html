💬 Comment demander la suppression de votre compte

La suppression s'effectue de manière sécurisée et définitive depuis l'application DelyGes. Pour des raisons de sécurité, vous devez être connecté et saisir votre mot de passe pour confirmer la suppression.

  1. Connectez-vous à l'application DelyGes avec votre compte (email et mot de passe).
  2. Ouvrez l'onglet Paramètres puis appuyez sur « Supprimer le compte ».
  3. Saisissez votre mot de passe pour vérifier votre identité.
  4. Confirmez la suppression. Cette action est irréversible.

Mot de passe oublié ? Sur l'écran de connexion, utilisez le lien « Mot de passe oublié » pour le réinitialiser avant de demander la suppression.

🗑️ Données supprimées

Lorsque vous supprimez votre compte, l'ensemble des données associées à votre compte est effacé :

  • Compte et identité : compte utilisateur, adresse email, identifiant Firebase, données de connexion et mot de passe (Firebase Authentication).
  • Profil et paramètres : nom, téléphone, SIRET, type de véhicule, TVA, objectifs financiers, préférences de notifications.
  • Activité : l'ensemble de vos livraisons, informations sur les destinataires, adresses de livraison, montants et données financières liées aux livraisons.
  • Commerçants : la liste de vos commerçants et les informations associées.
  • Données locales sur votre appareil : base de données locale (SQLite), notifications locales, session sécurisée et file de synchronisation.
  • Notifications : toutes les notifications programmées sur votre appareil sont annulées.

✓ Délai de suppression

La suppression est immédiate dès la confirmation dans l'application. Aucune période de conservation des données personnelles n'est appliquée après la suppression de votre compte.

Exception légale Si une obligation légale (comptable, fiscale ou judiciaire) l'exigeait, seules les données strictement nécessaires pourraient être conservées pendant la durée prévue par la loi, puis supprimées.

⚠️ La suppression est définitive et irréversible. Vos livraisons, commerçants, statistiques et paramètres ne pourront pas être restaurés.

📩 Autre moyen de demander la suppression

Si vous rencontrez un problème, vous pouvez nous contacter directement. Votre demande de suppression sera alors traitée manuellement après vérification de votre identité, dans un délai maximum de 30 jours.
